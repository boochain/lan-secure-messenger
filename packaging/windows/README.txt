局域网加密通讯 — Windows 便携版
================================

1. 双击「启动.bat」或 lan-gui.exe
2. 首次运行设置显示名称即可（无需安装/编译）
3. Windows 防火墙提示时，勾选「专用网络」允许
4. 关闭窗口后程序在托盘继续运行；托盘图标可恢复/退出
5. 命令行工具：lan-msg.exe doctor / peers / send / create-group ...

默认端口：UDP 41234（发现）+ TCP 41235（会话）
配置目录：%APPDATA%\FREC86\lan-secure-messenger\

字体说明
--------
程序已内置中文字体子集。也可将完整字体放入本目录 fonts\ 下以获得更全字形覆盖。
