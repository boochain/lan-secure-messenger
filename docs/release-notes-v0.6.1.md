## LAN Secure Messenger v0.6.1

所有版本（Windows WinUI 3、XP、Linux GTK 3 / GTK 4、Android）同步更新：

- **常用功能**：表情回应、回复引用、编辑/撤回、置顶会话、草稿、消息置顶与收藏、@提及、正在输入、转发、多选。
- **投票**：单选/多选，创建者可结束投票；旧版本对端收到纯文本。
- **会话分组 / 归档**：归档的会话收到新消息会自动回到列表（免打扰的除外）。
- **定时删除**：30 秒 / 5 分钟 / 1 小时 / 1 天 / 7 天，双方同步删除。
- **易用性**：二维码 / lsm:// 链接添加（指纹一致自动信任）、发送失败显示原因并一键重发、发送文件前显示大小和预计时间、Ctrl+K 快速切换会话、↑ 编辑上一条。
- **布局**：GTK 3 输入栏改为主流排列（表情、附件、输入框、发送），Ctrl+O 发送文件。
- **动画**：浅色主题下的页面与弹窗过渡动画更顺滑。
- **中继续传修复**：直连中断后自动改走中继并从已收到的位置续传，不再卡在“已发送”；传输停滞 20 秒自动重试。
- **稳定性**：GTK 4 打开消息菜单时不再被刷新打断；Windows 版 CI 界面与配色检查修复。
