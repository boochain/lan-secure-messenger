## LAN Secure Messenger v0.7.4

自 v0.7.3 以来。协议仍是 v5，各端互通。v0.7.3 发出去的 Android 包用的是调试证书，部分手机会报软件包无效。这一版起用固定的开发者证书，包名不变。装过那份调试包的手机要先卸载再装。

- **Android 安装包**：正式开发者证书签名，启动图标改为圆角聊天气泡。
- **Android 界面**：不再使用 Material You 的配色和底栏。页面、悬浮导航、卡片和自己的气泡改为不透明的玻璃色，圆角加大。Material 3 只保留文字、菜单和对话框。未信任的单聊在顶栏下有一条不随消息滚走的提醒，点一下即可信任；未信任时仍然不能发图片和文件。聊天搜索和对话框都能看清边界。深色模式下的在线绿点改亮，叠在头像上也能看清。
- **GTK**：按钮、气泡和菜单的圆角略加大，颜色仍在原来的调色板里。WinUI 和 XP 没有改成这套界面。
- **文件**：对方没有确认收完时会重试结束帧，超时后失败，并提示对方未确认文件已收完。
- **账号与中转**：中转数据目录固定，升级不删除旧目录，并保留上一份备份。恢复密钥和私钥不会写入日志。
