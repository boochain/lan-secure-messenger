## LAN Secure Messenger v0.6.0-beta.1（预发布 / 测试版）

> 草稿：尚未发布。正式发布前请按实际 CI 结果核对下面的文件清单。

从这个版本开始，**所有版本都在同一个仓库、同一个 Release 里发布**：Windows 10/11（x64 / arm64）、
Windows XP、Linux（GTK 4 与 GTK 3 兼容版）、Android，以及新增的**中转服务器**。

### 新功能：中转服务器（可选）

局域网之外、或者网络之间不能直接互通时（不同网段、公司隔离 VLAN、跨地点），可以在一台大家都能访问的机器上
运行中转服务器，各客户端在「设置 → 中转服务器（可选）」里填写地址和网络口令即可。

- **端到端加密不变**：中转服务器只转发已加密的数据，看不到消息和文件内容，也不保存任何聊天记录
- **直连优先**：能直连时自动走局域网直连；直连不通时自动改走中转服务器，联系人显示「经服务器」标记
- **传输中途切换线路不中断**：文件传输过程中从中转切到直连（或反过来）时，会先暂停再在新线路上从断点继续，
  不会重新开始，也不会失败
- **断点续传**：网络中断、中转服务器重启、任一方重启后，未完成的文件自动从断点继续，并校验已传部分（SHA-256）
- **网络口令**：只能写入，界面上不会再显示；口令错误时提示「网络口令错误」
- 中转服务器支持 Linux（x86_64 / aarch64 / armv7 / i686 / riscv64，静态链接）和 Windows（x64 / arm64 / x86），
  附带中文交互式部署脚本 `deploy.sh` / `deploy.ps1` / `deploy.bat`（安装、升级、卸载、状态查看）
- 部署脚本**不会自动修改防火墙**：防火墙未启用时只提示「本机防火墙未启用，不做修改」；已启用时先询问
  （默认「否」）并显示将要执行的命令；卸载时只删除脚本自己添加的规则。云服务器请记得在安全组里放行端口

### 界面改进

- 全平台统一使用「中转服务器」这一名称；联系人列表的简短标记为「经服务器」
- Windows：设置页各分区标题样式统一；传输页暂停中的任务显示为暂停状态
- Android：中转服务器开关整行可点击；口令已设置时显示「网络口令（已设置）」；连接中转服务器时状态栏显示「中转服务器」
- 所有版本的浅色 / 深色界面都经过自动截图和配色对比度审计

### 兼容性

- 与 v0.5.x 互通（局域网直连）；中转功能需要双方都升级到 v0.6
- 互通测试矩阵覆盖 Rust 版 ↔ C 版 ↔ Android 版，包括直连、中转、断点续传和传输中途切换线路（双向）

### 已知问题

- Windows arm64 版目前只做了构建和打包检查，没有在 arm64 真机上做界面测试
- 这是测试版，请先在非关键环境中使用；问题请到 Issues 反馈
