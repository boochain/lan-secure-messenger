## LAN Secure Messenger v0.7.1

所有版本（Windows WinUI 3、XP、Linux GTK 3 / GTK 4 + libadwaita、Android）同步更新。本版本包含自 v0.6.1 以来尚未单独发版的改动。

- **账号模式与设备模式**：首次启动可选择身份方式，之后也可在设置里更改。账号模式把端到端加密的身份与消息备份放在中转上，只有本机密钥能解密，服务器看不到明文；换机可用恢复密钥或配对二维码恢复历史和文件。设备模式仅本机、局域网直连，不把身份放到服务器。全程不使用服务器密码。
- **扫码与链接**：可用二维码或 `lsm://` 链接添加联系人、连接中转、配对新设备；支持粘贴链接和从图片识别。指纹一致会自动设为已信任。
- **会话操作对齐**：会话列表支持置顶、已读 / 未读、免打扰、删除；Android 左滑直接显示行内按钮，不必先弹出菜单。
- **看图与贴纸**：四端都可以全屏查看和缩放图片；表情与本地贴纸显示更稳定。
- **传输与重连**：传输更稳，失败不再长时间卡住；前台和主页会自动重连。发送图片可选压缩或原图。
- **独立页面**：聊天、联系人、群组、传输、文件、设置、个人资料、诊断拆成独立页面，各端功能对齐并有自动对照检查。
- **界面修正**：WinUI 首次启动对话框底部的防火墙提示不再被裁切；从图片识别得到的链接不再在输入框末尾出现方框乱码。
